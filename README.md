# Solstizio Studios Landing Page

This is a high-yield Airbnb design landing page for Solstizio Studios.

## Features
-   **Modern Design**: Built with Tailwind CSS and custom luxury color palette.
-   **Responsive**: Optimized for all screen sizes.
-   **Interactive**: Smooth scrolling and fade-in animations.
-   **ROI Calculator**: A lead generation form for potential clients.

## Technologies Used
-   [Tailwind CSS](https://tailwindcss.com/)
-   [Playfair Display & Lato Fonts](https://fonts.google.com/)
-   [Iconify](https://iconify.design/)
-   [Unsplash Images](https://unsplash.com/)

## How to View
Simply open `index.html` in any modern web browser.
